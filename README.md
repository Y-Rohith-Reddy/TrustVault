TrustVault — Secure Document Management System
Project Overview
TrustVault is a web application designed to help users manage their documents through an account-based interface.
Main Features
• User registration and login
• Dashboard and document management
• Document upload and download
• Document search and categories
• Activity logs and secure-session interface
Technology Stack
• Frontend: React, Vite, CSS
• Backend: Node.js, Express
• Database: SQLite
• Authentication: bcryptjs and JSON Web Tokens
Run Locally
Start the backend
Open a terminal in the project directory:
cd backend
npm install
node server.js
Start the frontend
Open a second terminal in the project directory:
npm install
npm run dev
Open the local URL shown by Vite in your browser.
Security Note
This project is a development prototype. Verify authentication, document access controls, upload validation, and secret management before using real or sensitive documents.
